# Abstract 

- Secure signup/login to all users.
- Role based authorisation of officer and supervisor.
- Session based authentication flow (persisting across restarts).
- Log audit trails for authentication paths.
- Have a centralised map for incident mapping.
- Incidents visible on the map which provide more information on click.
